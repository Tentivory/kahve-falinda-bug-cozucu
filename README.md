# Kahve Falında Bug Çözücü

**Dünyanın en ciddi, en bilimsel ve en saçma bug çözme aracı.**

Bu proje, geleneksel Türk kahve falı kültürünü modern yazılım mühendisliğiyle birleştirerek, her türlü bug'ı kökünden çözer. İnançsızlar için uyarı: Çalışır.

## Nasıl Çalışır?

1. Bir fincan Türk kahvesi için (gerçek kahve şart değil, hayalî de olur).
2. Bug açıklamanızı programa verin.
3. Program telvesi okur, falı yorumlar ve size **kesin çözüm** üretir.

## Kurulum

```bash
git clone https://github.com/Tentivory/kahve-falinda-bug-cozucu.git
cd kahve-falinda-bug-cozucu
python3 bug_cozucu.py "Null pointer exception, ruhum acıyor"
```

## Özellikler

- %100 gerçek fal okuma (rastgele ama ciddi).
- Her çözüm bilimsel olarak kanıtlanmıştır (kanıt: fal öyle söylüyor).
- Hiçbir dış bağımlılık yok. Sadece Python ve bir miktar çay/kahve.
- Bug'ları çözer, bazen de yeni bug üretir. Bu bir özelliktir.

## Uyarı

Bu araç gerçekten çalışır. Eğer bug'unuz çözülmezse, fincanı yıkayın ve yeniden deneyin. Hâlâ çözülmezse, bug zaten yoktu.
